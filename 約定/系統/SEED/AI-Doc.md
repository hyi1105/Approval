# AI Doc 規格（自 AI_MD）

最後更新：2026-08-09  
舊稱：SmartDoc／文稿。觸發：談「像 Cursor 改 MD＋顯示 Diff」時。

## 目標

讓 AI **針對同一份檔**下指令產生修訂，並以視覺化 Diff（紅刪／綠增）顯示修改處；Accept／Reject 後寫回同一份 Markdown。

## 核心

1. **AI 改檔**：自然語言指令；主流程不是另開無關新檔。  
2. **顯示修改處**：Diff 為主路徑；優先於 P2P／分紅等。  
3. **同一份持續編修**：底層 Markdown；可切預覽模式（合約／流程圖／報告等）。  
4. **輔助**：指紋／P2P／額度若做，須標示範或次要。

## 與主題

```text
AI 查詢（找素材）→ AI Doc（改檔＋Diff）→ 累積成知識書
```

## 邊界（舊站曾達）

| 項目 | 狀態 |
|------|------|
| 指令改同一份檔＋Diff | 曾可用（示範規則引擎，非真 LLM） |
| Accept／Reject | 曾可用 |
| 真 LLM／真 P2P | 見 `個人/idea.md` waiting-owner |

程式本體未併入本庫；要重做時以本規格＋idea 為準。
