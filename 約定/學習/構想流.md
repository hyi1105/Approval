# 構想流（突發奇想怎麼收）

最後更新：2026-08-09  
來源精簡自 AI_MD `AGENT-MASTER`／idea 分工。  
觸發：你丟想法、語音奇想、說「記一下」「寫進 idea」。

## 流轉（硬性）

```text
你分享想法／語音
  → AI 改寫繁中、補齊模板
  → 追加到 個人/idea.md（最新在上）

做成／決定不做／過期結案
  → 該則移到 個人/idea.history.md
  → idea.md 保持精簡（省 token）

若將來有「線上產品」要防回歸
  → 另建該產品的 checklist（查核表≠許願池）
  → 沒有線上產物就不要為空想建 checklist
```

| 你說 | AI 做 |
|------|--------|
| 想法／奇想／記一下 | **只改** `個人/idea.md`（完整欄位） |
| 這則結案／不做了 | 移到 `idea.history.md` |
| 改程式／實作 | 才動 code（若有專案） |
| 查核 checklist | 僅當該產品有查核表時才做 |
