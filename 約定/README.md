# 約定總覽（Agent 入口）

> **目的：** 省 token、好改、可累積口味。不要整包讀完。  
> **最後更新：** 2026-08-09

## 讀取規則（強制）

| 時機 | 必讀 | 不要讀 |
|------|------|--------|
| **每次回覆前** | [`核心.md`](./核心.md) | 其餘檔（除非下面觸發） |
| 在教／開關卡 | + [`學習/節奏與工具.md`](./學習/節奏與工具.md) | — |
| 做 NotebookLM 語音 | + [`學習/NotebookLM.md`](./學習/NotebookLM.md) | — |
| 談英語郵件 | + [`個人/英語.md`](./個人/英語.md) | — |
| 續 dive-into-llms | + [`學習/dive-into-llms.md`](./學習/dive-into-llms.md) | — |
| 做／談簽核 Approval | + [`系統/Approval.md`](./系統/Approval.md) | — |
| 陌生系統／改來源衝擊 | + [`系統/system-map/SKILL.md`](./系統/system-map/SKILL.md)；需要再讀同資料夾 `references/` | — |
| 主線要對齊時 | + [`系統/主線.md`](./系統/主線.md) | — |
| 想更合口味 | + [`個人/口味累積.md`](./個人/口味累積.md) | — |

貼給外部 Agent：只用 [`學習/給其他Agent可貼版.md`](./學習/給其他Agent可貼版.md)，不要貼整庫。

## 資料夾

| 資料夾 | 放什麼 | 何時長大 |
|--------|--------|----------|
| `個人/` | 語言以外的偏好、英語、**口味累積** | 你說「以後都這樣」→ 寫進口味累積 |
| `學習/` | 關卡節奏、NotebookLM、課進度、可貼版 | 換教材／改學法時 |
| `系統/` | 簽核構想、system-map 方法論 | 開新系統／改產品時 |

## 怎麼改約定（省事版）

1. 對話裡講清楚新規則或新口味。
2. Agent **只改對應那一個小檔**，並在該檔頂更新「最後更新」。
3. **禁止**為了省事又把內容併回單一巨檔。
4. 口味／厭惡／比喻偏好 → 一律追加 [`個人/口味累積.md`](./個人/口味累積.md)（條列，短句）。
5. 會影響「每次回覆」的硬規則 → 才改 [`核心.md`](./核心.md)（保持短）。
6. 推上 GitHub；以倉庫檔為準，不以聊天記憶為準。
