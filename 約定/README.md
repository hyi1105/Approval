## 資料夾

| 資料夾 | 放什麼 | 何時長大 |
|--------|--------|----------|
| `個人/` | 口味累積、英語、**idea／idea.history** | 奇想→idea；「以後都這樣」→口味 |
| `學習/` | 關卡節奏、NotebookLM、課進度、構想流、可貼版 | 換教材／改學法時 |
| `系統/` | 簽核、system-map、artifact-lens、**SEED** | 開新系統／改產品時 |

## 怎麼改約定（省事版）

1. 對話裡講清楚新規則或新口味。
2. Agent **只改對應那一個小檔**，並在該檔頂更新「最後更新」。
3. **禁止**為了省事又把內容併回單一巨檔。
4. 口味／厭惡／比喻偏好 → 一律追加 [`個人/口味累積.md`](./個人/口味累積.md)（條列，短句）。
5. 突發產品／專案奇想 → 追加 [`個人/idea.md`](./個人/idea.md)（完整 Why／What／How…）。
6. 會影響「每次回覆」的硬規則 → 才改 [`核心.md`](./核心.md)（保持短）。
7. 推上 GitHub；以倉庫檔為準，不以聊天記憶為準。
