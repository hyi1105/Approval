# 口味累積（越寫越準）

最後更新：2026-08-14  
**用途：** 把「以後都這樣／不要那樣」收成短條，讓回覆越來越合味。  
**寫法：** 一行一條；標 `喜歡`／`討厭`／`比喻`／`情境`；不要長文。

## 喜歡

- （待累積）關卡＋完成％＋過關結算
- （待累積）先地圖再細節
- （待累積）短決策題、生活比喻
- 結構／程式／血緣／流程／跑指令前 →「說明法」：真實樹＋同行旁註；一次≤5；空一行接續（規則：`.cursor/rules/說明法.mdc`）

## 討厭

- （待累積）無限追問、沒結算
- （待累積）長篇灌輸、播報腔、大陸用語
- （待累積）整句粗體刷屏
- 說明時用房間／故事比喻、職稱標籤腔、虛流程、一次>5、沒介紹就叫 Run

## 常用比喻／詞庫

- 冰箱＝資料家（主錨 3）
- Skill／SOP ≠ 訓練權重；提示＝當下怎麼答

## 情境筆記

- 工作背景常碰：簽核、Excel 匯入、PBI、Power Apps、SharePoint、Java、Notes
- 偏好：舊系統冷凍；新層設定驅動；沒說一聲不要開做大系統
- 突發奇想多 → 收進 `個人/idea.md`，不要跟口味條混在一起
