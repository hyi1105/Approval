## 2026-08-13 — 任意系統 → 可操作網頁（View＋Play）

- 狀態：open  
- 來源：對話（「能不能把任何系統變成網頁版？不只看，還能直接用」）  
- 為什麼（Why）：地圖／說明只能看；真正懂系統要能「填、走流程、換角色」；最好還能當輕量替代介面。  
- 做什麼（What）：分三層，不要承諾「任意系統一鍵變正式系統」：  
  1. **View**：說明／地圖網頁（只讀）  
  2. **Play**：沙盒可操作（填表、換角色、模擬簽核／條件；資料不進公司正式庫）  
  3. **Run**：真上線可用（登入、存檔、通知、接 SharePoint／API）— 只對「表單＋流程型」系統務實，不是任意 ERP／厚客戶端都能一鍵取代  
- 怎麼做（How）：  
  1. 輸入先走 Artifact Lens → `map` 產出 system-map JSON（12345）。  
  2. Play：用 JSON 驅動單頁（欄位座標固定、只改 paint；規則見 system-map `output-views` §G）；本庫靜態模擬頁曾有過、已刪，可重建。  
  3. Run：接主線 Approval（紙本風＋schema＋SharePoint／個人空間），一系統一條線，不要「萬用產生器」一次吃全世界。  
- 優點（Pros）：View／Play 啟動低、合「先地圖再細節」；Run 有 Approval 現成產品記憶。  
- 缺點／風險（Cons）：Power Automate／C# 業務邏輯難完整重播；真 Run 要權限與資安；「任意」會變成無底洞。  
- 不做的替代方案：對話裡用 system-map 口頭模擬角色×情境；或只產 Mermaid／說明頁。  
- 完成後可查核的一句（若將來有產品）：丟進系統描述，打開網頁能換角色填完一條故事流程（Play）；選中的系統能真送一筆（Run）。  
- 待拍板：下一刀做「重建 Play 靜態頁」還是「Approval Run 復活」；Play 是否成為 artifact-lens 的 `play` 鏡片。  
- 難點診斷（2026-08-13）：不是「流程 vs 素材」二選一。  
  - **View／map**：常卡在素材缺「3 資料家＋4 誰可編」；流程故事（2）缺了仍能畫草稿。  
  - **Play**：最難是權限瀑布與欄位來源不夠＝素材／規則洞，不是網頁技術。  
  - **Run**：最難是真身分、真存檔、真副作用與整合；流程寫清也救不了。  
  - 流程不清會痛，但通常是第二刀；第一刀失敗多半是**關鍵欄從哪來、誰能動、寫去哪**沒在素材裡。  
- 保真範圍修正（2026-08-13，owner）：**不要長得一模一樣。**  
  - 要一樣：輸入／輸出的**動作**（按什麼會發生什麼）；欄位**可編／不可編／必填**；呈現的**資訊內容**一致。  
  - 可不同：畫面排列、視覺、版型；隨時可換成另一套 UI，行為契約不變。  
  - 因此最難收成：**行為契約表**（欄位狀態＋動作），不是畫像素；素材若只有截圖沒有「誰可編／必填」，才會卡死。  
  - 定調補充：要的是**單一理智流程所需資訊齊全且行為一致**；**不同系統／不同流程的契約本來就不同**——可接受，不要強求萬用同一張表。

## 2026-08-13 — 任意檔案鏡片（Artifact Lens）

- 狀態：building  
- 來源：對話（「不要丟程式／PDF 才看得懂；SQL／C#／Power Automate／學生版／地圖」）  
- 為什麼（Why）：下載來的東西語言各異，想直接「變成我看得懂的版本」或一張地圖，而不是自己硬啃原文。  
- 做什麼（What）：輸入任意產物（程式、流程匯出、PDF／文件、試算表），自動辨識類型，再用選定「鏡片」輸出：母語說明、學生版、或 system-map 地圖。  
- 怎麼做（How）：  
  1. 先做薄 Skill（本庫已開工：`約定/系統/artifact-lens/`），Cursor 裡丟檔＋一句話即可。  
  2. 鏡片：`native`（同領域白話）、`student`（學生可讀）、`map`（接 system-map 12345）。  
  3. 不做大產品站；與 SEED／AI Doc 有關時再接知識書路線。  
- 優點（Pros）：啟動成本低；已有 system-map 可接；合「先地圖再細節」口味。  
- 缺點／風險（Cons）：大檔／模糊 PDF 可能漏；Power Automate JSON 雜訊多；學生版易過度簡化。  
- 不做的替代方案：每次手動叫 `/system-map` 或口頭說「講成學生版」。  
- 完成後可查核的一句（若將來有產品）：丟進一檔，一分鐘內拿到可讀說明或一張 12345 地圖。  
- 待拍板：要不要升級成獨立產品／SEED 工具層；預設鏡片要不要固定成 `map`。
