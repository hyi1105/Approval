# 環島路線工具（SEED）

線上：https://hyi1105.github.io/AI_MD/trip-tool/

依**地址／座標**在台灣地圖上標註停留點、畫出實際路線，並顯示：

- 每個停留點的**停留時間**（抵達～離開）
- **點到點騎乘時間**（依行程時刻，並用 OSRM 估算實際路線距離／時間）
- 每個停留點可**上傳照片**
- 匯出／匯入 JSON，資料存在瀏覽器 `localStorage`

## 本機

在 `web/` 啟動本機伺服器後開啟 `/trip-tool/`：

```powershell
cd web
.\start-local.ps1
```

（地圖圖磚、地址搜尋、路線規劃需要網路。）

### 操作

1. 點 **載入範例** 可看環島行程
2. **＋ 新增停留點** 或 **貼上行程文字**
3. 拖曳地圖標記微調位置後按 **規劃路線**
4. 點停留點可上傳照片

## 技術

Leaflet + OpenStreetMap · Nominatim · OSRM · 純靜態前端
