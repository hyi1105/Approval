# 環島路線工具（網頁）

依**地址／座標**在台灣地圖上標註停留點、畫出實際路線，並顯示：

- 每個停留點的**停留時間**（抵達～離開）
- **點到點騎乘時間**（依行程時刻，並用 OSRM 估算實際路線距離／時間）
- 每個停留點可**上傳照片**
- 匯出／匯入 JSON，資料存在瀏覽器 `localStorage`

## 怎麼用

用瀏覽器直接打開：

```bash
cd trip-tool
python3 -m http.server 8080
# 開 http://localhost:8080
```

（地圖圖磚、地址搜尋、路線規劃需要網路。）

### 操作

1. 點 **載入範例** 可看 2026/07/26 環島行程
2. **＋ 新增停留點**：填名稱、地址 → 按「定位」→ 設抵達／離開時間 → 上傳照片 → 儲存
3. 也可**拖曳地圖標記**微調位置，再按 **規劃路線**
4. 側欄會顯示每段「騎乘 X 分 →」與各點停留時間
5. 左上角／側欄統計：總長、騎乘、停留、總時

### 匯出給別人

按 **匯出 JSON**。對方用 **匯入** 即可還原（含壓縮後的照片）。

## 技術

| 項目 | 方案 |
|------|------|
| 地圖 | Leaflet + OpenStreetMap |
| 地址定位 | Nominatim（台灣） |
| 路線 | OSRM public driving API |
| 照片 | 前端壓縮成 JPEG data URL，存 localStorage |

> 純靜態頁，不需後端。若 OSRM 暫時失敗，會退回直線連線並用行程時刻算時間。

## 與拼貼模板的關係

`../trip-collage/` 仍是 3×2 照片拼貼產生器。  
本工具是**地圖路線版**——依真實地理位置呈現，而不是固定九宮格。
